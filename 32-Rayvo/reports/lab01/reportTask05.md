## Задача 5. Сумма элементов на чётных позициях

Дан массив из n целых чисел. Найти сумму элементов с чётными индексами (0, 2, 4, …). Требуется O(n).

### Идея решения

Используется один линейный проход по массиву с шагом 2.
Счётчик `sum` инициализируется нулём, цикл `for (int i = 0; i < array.length; i += 2)` сразу перебирает только чётные индексы и прибавляет `array[i]` к сумме.
Проверка `i % 2 == 0` внутри цикла не нужна — шаг 2 её заменяет и вдвое сокращает число итераций.
Сумма накапливается в `long`, чтобы избежать переполнения `int` при больших значениях элементов.
Массив `null` и пустой массив дают `0` — по условию это сумма, а не признак «найдено/не найдено».

### Асимптотика

Используется один линейный проход по массиву с шагом 2. Цикл `for (int i = 0; i < array.length; i += 2)` сразу перебирает только чётные индексы и накапливает сумму в переменной типа `long`.
Проверка `i % 2 == 0` внутри цикла не нужна — шаг 2 её заменяет и вдвое сокращает число итераций. Итого получаем `O(n)`.

**Время:** `O(n)` — n/2 итераций, на каждой O(1).
**Доп. память:** `O(1)` — только переменная sum типа long.

### Проверки
Согласно JaCoCo покрытие тестами ветвлений составляет 100%.
- `shouldSumEvenIndicesInUnsortedArray` — `5 4 9 2 7 5` → 11: индексы 0, 2, 4 → 4 + 2 + 5.
- `shouldSumEvenIndicesWhenLengthIsOdd` — `7 1 2 3 4 5 6 7` → 16: индексы 0, 2, 4, 6 → 1 + 3 + 5 + 7.
- `shouldSumOnlyFirstElementWhenArrayHasOneElement` — `1 42` → 42: один элемент, сумма = `a[0]`.
- `shouldHandleAllZeros` — `4 0 0 0 0` → 0: все нули.
- `shouldHandleNegativeNumbers` — `5 -8 3 -14 6 -2` → -24: индексы 0, 2, 4 → -8 + (-14) + (-2).
- `shouldHandleMixedSigns` — `5 -5 10 0 -3 7` → 2: индексы 0, 2, 4 → -5 + 0 + 7.
- `shouldNotOverflowOnLargeValues` — `3 MAX 0 MAX` → 2 * MAX: проверка отсутствия переполнения int.
- `shouldUseZeroBasedIndexingNotOneBased` — `4 10 20 30 40` → 40: именно нулевая индексация (0, 2), а не «с первой позиции».
- `shouldNotModifyOriginalArray` — `5 4 9 2 7 5` → исходный массив не изменяется: проверка отсутствия побочных эффектов.
