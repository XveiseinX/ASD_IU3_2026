## Задача 4. Все индексы элемента

Дан массив из n целых чисел и число x. Найти все индексы элементов, равных x, в порядке возрастания. Требуется O(n).

### Идея решения

Используются два линейных прохода по массиву.
Первый проход подсчитывает количество элементов, равных `x` (аналогично задаче 3).
Второй проход заполняет массив индексов ровно нужного размера: при каждом совпадении текущий индекс записывается в результат.
Поскольку второй проход идёт слева направо, индексы автоматически оказываются в порядке возрастания.
Возвращается `int[]`; если вхождений нет, возвращается пустой массив.
В `main` пустой результат выводится как `-1` — согласовано с задачей 2 («если не найдено — `-1`»), а непустой — как индексы через пробел.

### Асимптотика

Используются два линейных прохода по массиву. Первый проход подсчитывает количество вхождений `x` (аналогично задаче 3),
второй — заполняет массив индексов ровно нужного размера, записывая текущий индекс при каждом совпадении. Поскольку второй проход идёт слева направо,
индексы автоматически упорядочены по возрастанию. Итого получаем `O(n)`.

**Время:** `O(n)` — два прохода по n итераций, на каждой O(1).
**Доп. память:** `O(k)`, где k — количество вхождений; в худшем случае `O(n)` для массива индексов.
