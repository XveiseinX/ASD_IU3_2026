## Задача 27. Сумма квадратов

Дан массив из n целых чисел. Найти сумму квадратов всех элементов. Требуется O(n).

### Идея решения

Используется один линейный проход по массиву.
Переменная `sum` имеет тип `long` и инициализируется нулём.
Для каждого элемента вычисляется его квадрат и прибавляется к `sum`.
Квадрат вычисляется как `(long) value * value`: приведение к `long` выполняется **до** умножения, иначе произведение `int * int` может переполниться (например, `50000 * 50000 = 2_500_000_000 > Integer.MAX_VALUE`) и дать отрицательное значение.
Тип `long` также вмещает сумму квадратов без переполнения: `Long.MAX_VALUE ≈ 9.22 * 10^18`.
Знак элемента не важен — квадрат всегда неотрицателен.
Массив `null` и пустой массив дают `0` — по условию возвращается сумма, а не признак «найдено/не найдено».

### Асимптотика

Используется один линейный проход по массиву. Переменная `sum` типа `long` инициализируется нулём; для каждого элемента вычисляется `(long) value * value` и прибавляется к `sum`.
Приведение к `long` до умножения исключает переполнение `int` на промежуточном шаге (например, `50000 * 50000 > Integer.MAX_VALUE`). Тип `long` вмещает и сумму квадратов без переполнения. Итого получаем `O(n)`.

**Время:** `O(n)` — ровно n итераций, на каждой O(1).
**Доп. память:** `O(1)` — только переменная sum типа long.

### Проверки

- `4 1 2 3 4` → 30: положительные числа.
- `2 -3 -4` → 25: отрицательные числа, знак не важен.
- `4 -2 3 -1 4` → 30: смешанные знаки.
- `4 0 0 0 0` → 0: все нули.
- `1 7` → 49: один элемент.
- `1 50000` → 2_500_000_000: квадрат переполняет int, но long вмещает.
- `1 -50000` → 2_500_000_000: отрицательное значение с переполняющим квадратом.
- `1 MIN` → 2^62: Integer.MIN_VALUE в квадрате помещается в long.
- `3 10^9 10^9 10^9` → 3 * 10^18: большая сумма без переполнения long.
