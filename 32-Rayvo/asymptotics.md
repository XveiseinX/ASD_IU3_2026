### Задача 1. Максимум и минимум
Используется один линейный проход по массиву. `min` и `max` инициализируются первым элементом, затем на каждой итерации текущий элемент сравнивается с обоими значениями и при необходимости обновляет их. Сортировка и дополнительные структуры данных не нужны. Итого получаем `O(n)`.

Инициализация и цикл:
int min = array[0];
int max = array[0];

for (int i = 1; i < array.length; i++) {
if (array[i] < min) {
min = array[i];
}
if (array[i] > max) {
max = array[i];
}
}

**Время:** `O(n)` — n - 1 итераций, на каждой O(1).
**Доп. память:** `O(1)` — две переменные min и max.
### Задача 2. Индекс первого вхождения
Используется один линейный проход по массиву слева направо. На каждой итерации текущий элемент сравнивается с искомым `x`; при первом совпадении сразу возвращается индекс. Если цикл завершился без совпадений — возвращается `-1`. Проход слева направо гарантирует, что найден именно первый элемент, равный `x`. Итого получаем `O(n)`.

Цикл поиска:
for (int i = 0; i < array.length; i++) {
if (array[i] == x) {
return i;
}
}
return -1;

**Время:** `O(n)` — в худшем случае n итераций, на каждой O(1). При первом совпадении работа прекращается досрочно, но верхняя оценка — `O(n)`.
**Доп. память:** `O(1)` — только счётчик цикла `i`.
### Задача 3. Подсчёт вхождений
Используется один линейный проход по массиву. Счётчик `count` инициализируется нулём; для каждого элемента проверяется равенство с `x`, при совпадении счётчик увеличивается. В отличие от поиска первого вхождения, досрочный выход невозможен — нужно просмотреть весь массив, чтобы посчитать все вхождения. Итого получаем `O(n)`.

Цикл подсчёта:
int count = 0;
for (int value : array) {
if (value == x) {
count++;
}
}
return count;

**Время:** `O(n)` — ровно n итераций, на каждой O(1).
**Доп. память:** `O(1)` — только счётчик count.
### Задача 4. Все индексы элемента
Используются два линейных прохода по массиву. Первый проход подсчитывает количество вхождений `x` (аналогично задаче 3), второй — заполняет массив индексов ровно нужного размера, записывая текущий индекс при каждом совпадении. Поскольку второй проход идёт слева направо, индексы автоматически упорядочены по возрастанию. Итого получаем `O(n)`.

Первый проход (подсчёт):
int count = 0;
for (int value : array) {
if (value == x) {
count++;
}
}

Второй проход (заполнение индексов):
int[] indices = new int[count];
int pos = 0;
for (int i = 0; i < array.length; i++) {
if (array[i] == x) {
indices[pos++] = i;
}
}

**Время:** `O(n)` — два прохода по n итераций, на каждой O(1).
**Доп. память:** `O(k)`, где k — количество вхождений; в худшем случае `O(n)` для массива индексов.
### Задача 5. Сумма элементов на чётных позициях
Используется один линейный проход по массиву с шагом 2. Цикл `for (int i = 0; i < array.length; i += 2)` сразу перебирает только чётные индексы и накапливает сумму в переменной типа `long`. Проверка `i % 2 == 0` внутри цикла не нужна — шаг 2 её заменяет и вдвое сокращает число итераций. Итого получаем `O(n)`.

Цикл суммирования:
long sum = 0L;
for (int i = 0; i < array.length; i += 2) {
sum += array[i];
}
return sum;

**Время:** `O(n)` — n/2 итераций, на каждой O(1).
**Доп. память:** `O(1)` — только переменная sum типа long.
### Задача 6. Элементы больше среднего
Используются два линейных прохода по массиву. Первый проход вычисляет сумму всех элементов (в `long`, чтобы избежать переполнения `int`); среднее вычисляется как `sum / n` — по гарантии условия деление целое. Второй проход подсчитывает элементы, строго большие среднего (`value > average`). Итого получаем `O(n)`.

Первый проход (сумма):
long sum = 0L;
for (int value : array) {
sum += value;
}
long average = sum / array.length;

Второй проход (подсчёт):
int count = 0;
for (int value : array) {
if (value > average) {
count++;
}
}
return count;

**Время:** `O(n)` — два прохода по n итераций, на каждой O(1).
**Доп. память:** `O(1)` — только sum, average и count.
