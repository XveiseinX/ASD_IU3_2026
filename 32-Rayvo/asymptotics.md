### Задача 1. Максимум и минимум
Используется один линейный проход по массиву. `min` и `max` инициализируются первым элементом, затем на каждой итерации текущий элемент сравнивается с обоими значениями и при необходимости обновляет их. Сортировка и дополнительные структуры данных не нужны. Итого получаем `O(n)`.

Инициализация и цикл:
int min = array[0];
int max = array[0];

for (int i = 1; i < array.length; i++) {
if (array[i] < min) {
min = array[i];
}
if (array[i] > max) {
max = array[i];
}
}

**Время:** `O(n)` — n - 1 итераций, на каждой O(1).
**Доп. память:** `O(1)` — две переменные min и max.
### Задача 2. Индекс первого вхождения
Используется один линейный проход по массиву слева направо. На каждой итерации текущий элемент сравнивается с искомым `x`; при первом совпадении сразу возвращается индекс. Если цикл завершился без совпадений — возвращается `-1`. Проход слева направо гарантирует, что найден именно первый элемент, равный `x`. Итого получаем `O(n)`.

Цикл поиска:
for (int i = 0; i < array.length; i++) {
if (array[i] == x) {
return i;
}
}
return -1;

**Время:** `O(n)` — в худшем случае n итераций, на каждой O(1). При первом совпадении работа прекращается досрочно, но верхняя оценка — `O(n)`.
**Доп. память:** `O(1)` — только счётчик цикла `i`.
